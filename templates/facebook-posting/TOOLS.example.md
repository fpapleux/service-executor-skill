# Local tool configuration contract

Operator example only. Actual values and tool access instructions are private deployment inputs. Do not treat unset fields as configured access. Keep this local tool/how-to information separate from business conditions in the four injections.

| Field | Operator supplies privately |
| --- | --- |
| Browser backend and profile | Explicit authorized supported backend/profile selection |
| Browser tool procedure | Available tool connection/selection and API documentation access; no outside skill dependency |
| Shared resource key | Canonical identity of the actual shared browser profile/session across requests and Pages |
| Upload prerequisites | Supported attachment method, path visibility and required already-enabled permissions |
| Native capabilities | Observed Page access, feed-image posting and scheduling capability if requested |
| Communication channel/procedure | Explicit authorized customer route, tool access and documented submission operation |
| Communication fields | Required configured identity/recipient/destination for that chosen channel |
| Communication evidence | Submission acknowledgement and reconciliation/query capability for uncertain attempts |
| Private record root | Durable private location accessible to future authorized sessions |
| Ownership facility | Existing exclusive lock facility and stable shared lock paths usable throughout tool operations |
| Operator change-request route | Authorized place to file separate improvement proposals |
| Credential references | Private reference mechanism only; never credential values in records/public files |

No fields above supply real account access. Configuration must state how to operate the actual available tools; a field naming a channel alone is insufficient. Discover current tool schemas as allowed by the configured access, without loading another workflow skill. Reporting may use a customer portal, a session reply or another authorized channel; any channel-specific required fields must be explicitly set.

If prerequisite access is absent, report the observed blocker. Executing agents do not provision services, guess identity/recipient settings or change browser security controls.
